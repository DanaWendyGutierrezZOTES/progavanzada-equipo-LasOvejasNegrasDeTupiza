# TicketEventos - Frontend en React

Plataforma de compra y gestión de entradas desarrollada en **React (Vite)**.

## Cómo Iniciar el Proyecto

1. Abrir la terminal en la carpeta `frontend`:
   ```bash
   cd frontend
   ```

2. Instalar dependencias (solo la primera vez, ya han sido instaladas):
   ```bash
   npm install
   ```

3. Iniciar el servidor local de desarrollo:
   ```bash
   npm run dev
   ```

4. Abre en tu navegador la URL:
   `http://localhost:3000`

---

## Usuarios de Prueba Disponibles

Para probar y defender el proyecto fácilmente, puedes usar los botones de acceso rápido en la barra superior o en el login:

| Rol | Usuario | Contraseña | Capacidades |
|---|---|---|---|
| **Organizador** | `organizador` | `123` | Crear eventos, gestionar entradas, ver métricas de ventas y recaudación |
| **Comprador** | `comprador` | `123` | Explorar cartelera, comprar entradas, ver sus tickets digitales |
| **Administrador** | `admin` | `123` | Acceso a todas las funciones |
